머니파이가 처음이신가요?

Q. 무슨 앱이에요?
여러 증권사에 흩어진 연금저축·IRP·ISA·직투 계좌를 한곳에 모아서, 내 자산이 어떻게 배분되어 있는지 한눈에 보여주는 도구예요. 숫자를 입력해두면, 가계부처럼 자산이 어떻게 변해왔는지 보여요.
Q. 내 자산 정보, 어디로 새는 거 아니에요?
로그인도, 증권사 연동도 없어요. 입력한 데이터는 지금 쓰는 브라우저 안에만 저장되고 어떤 서버로도 전송되지 않아요.
Q. 왜 자동으로 연동 안 되고 직접 입력해야 해요?
증권사 자동연동 앱은 로그인 정보와 자산 데이터를 다른 서버에 넘겨야 해요. 약간의 수고 대신 안전함을 택했어요. 종목명 입력은 코드/티커/키워드가 적용돼서 생각보다 손이 많이 안 가요.
Q. 다른 자산관리 앱이랑 뭐가 달라요?
여러 계좌에 흩어진 종목을 섹터별·국내해외별·계좌유형별로 보여줘요. 섹터별 비중뿐 아니라, 무엇보다 중요한 현금비중 관리도 직관적으로 보여요.
Q. 모바일에서도 잘 되나요?
모바일 기준으로 먼저 만들어졌어요. 물론 PC에서도 잘 보여요.
Q. 휴대폰 바꾸면 데이터 다 날아가나요?
기기를 바꾸거나 브라우저 데이터를 지우면 데이터도 같이 사라져요. 그래서 데이터 저장하기/불러오기 기능을 넣어뒀어요. 데이터 저장하기 해두셨다가, 새 기기나 PC에서 불러오기 하시면 그대로 이어져요.
Q. 앞으로도 계속 유지 관리되나요?
처음부터 제가 쓰려고 만든 도구라서 계속 관리돼요. 안심하고 쓰셔도 됩니다.
