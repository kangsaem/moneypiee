DTMD 다이빙 플래너 / 로그북

v2.1.8 기준 · 2026-11-08 · moneypie.kr/scuba.html

1장점

1. 튜토리얼

  • 3분 만에 익히는 초보자용 핵심 기능.
  • 그래프를 드래그하며 무감압·감압 다이빙의 차이, 수심과 질소의 관계 같은 기초 필수 개념을 쉽게 익힘.

2. FIT 분석

  • FIT 연동, 위반 지점을 시각적으로 표시.
  • 그래프 수정으로 사후 시뮬레이션 가능.
  • 직관적으로 볼 수 있는 다이빙 개선 도구.
  • 직접 그래프를 그려서 로그 작성도 가능.

3. GPS 지도 · 사진 로그

  • FIT 연동 입·출수 지점 수정 및 등록.
  • 포인트별 사진 등록 및 포토로그 저장.
  • 직접 포인트를 찾아서 로그 작성도 가능.

4. 일반 방식 / 쉐어워터 방식

  • 구획별 질소를 두 방식으로 시각화.
  • GF·보수성·기체·상승 속도별 감압 의무를 즉시 비교.
  • 반복 다이빙 잔류 질소 확인.
2정체
  • 웹 앱. 설치 불필요.
  • 한국어·영어·일본어 지원.
3계산 모델
  • Bühlmann ZHL-16C, 질소 16구획.
  • Baker GF. 기본 40/85, 직접 입력 가능.
  • 1초 단위 계산. 수증기압 0.0627 bar 반영.
  • 감압 정지 3 m·1분 단위. 마지막 정지 3 m.
  • 5 m 3분 안전정지 포함.
  • CNS%만 NOAA 한도로 계산. OTU·헬륨은 미계산.

5플래너
  • 도구: 그리기 / 점찍기 / 점지우기 / 실행취소 / 지우기.
  • 추천 경로(감압·안전정지) 자동 연장.
  • 반복 다이빙: [+] 탭 추가 + 수면휴식 시간 입력 → 잔류 질소 이어서 계산.
  • 재생 0.5/1/2×. 막대로 시점 이동.
  • 지표: 경과 시간, 수심, NDL/천장, TTS, 수면 GF, GF99, PO₂, CNS, 잔압.

그래프 배경 [사진] · [지도]

  • 메모에 GPS가 있으면 35~70분 구간에 입·출수 지점 지도.
  • 메모에 GPS 줄이 없고 장소: 같은 지명 줄만 있으면 지명 검색 위치를 점 없이 보여 줌.
  • 로그 수정창에서 세부 설정 가능.
7질소막대
  • 두 방식: 수면 기준(수면 M값 대비 %), 쉐어워터식(흡입 질소·주변압·M값·GF 한계).
  • 색: 흡수(빨강) / 배출(파랑) / 평형.
  • 구획 누르면 반감기·질소 분압·% 표시.
8로그북
  • 달력 ↔ 일별 보기. 누르면 선택, 한 번 더 누르면 들어감.
  • 이전/다음 로그, 달 이동.
  • 하루 = 기록 1개. 그 안에 다이빙 1·2…
  • 로그 줄 정보. 선택된 줄을 다시 누르면 반접기 토글.
  • 수정: 입수 시각 휠·메모·사진. [저장] / [취소].
  • 저장 안 한 변경은 다른 날짜나 플래너로 가면 버림.
  • 사진: 다이빙당 10장. 기기 안에 저장.
  • 접힘 3단계. 마지막 상태 기억(질소막대·시뮬레이션 탭 포함).
  • 플래너 → 로그북 전환 시 해당 로그를 빠르게 그려 보여줌.
9FIT 불러오기
  1. [FIT] → 폴더 고르기 → 하위 폴더까지 .fit 검색. PC 크롬·엣지, iOS 18.4+.
  2. 폴더를 못 고르는 기기는 파일 고르기(FIT·ZIP).
  3. 자동 제외: 비다이빙, 프리다이빙(apnea 또는 3분 안 수면 상승), 이미 불러온 기록.
  4. 불러오기 전 요약 확인.
  • 직접 쓴 로그와 겹치면 수심만 교체. 메모는 유지.
  • GPS 좌표·지명(OpenStreetMap)·수온을 메모에 기록.
  • 위반 화살표는 FIT 로그에도 표시.
10출력·공유·화면·주소
  • 출력: 데이터 로그 이미지, 포토로그, 스냅샷.
  • 백업: 사진 포함 ZIP 저장. ZIP/JSON 불러오기.
  • 화면: 1단 / 2단(780–1169px, 재생 버튼·범례 재배치) / 3단(1170px+).
  • 휴대폰 가로: 메뉴 숨김. 그래프 탭이 화면에 꽉 맞음.
